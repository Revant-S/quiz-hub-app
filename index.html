Connect to GitHub

Quiz Hub keeps your quizzes and progress in two secret gists on your GitHub account, so all your devices stay in sync. Paste a token that can access gists.

  1. Open github.com/settings/tokens/new (classic token).
  2. Tick only gist, choose an expiry, press Generate token.
  3. Paste it below. Use the same token on every device.

The token stays on this device, in this app's storage. It is sent only to api.github.com.

Settings

Forgetting the token does not delete anything on GitHub. Your progress stays in the gist.
